Task-Aware Object Identification for Assistive Robotics using PYNQ-Z2

Tell the robot what you need. It finds the object.

An assistive robot doesn't get class names, it gets requests like "something to drink from". This system detects every object in the scene on the PYNQ-Z2 FPGA, then ranks each one against your request with CLIP embeddings to pick the single object that fits.

    Assistive robotics

    Who this helps

    People who need help with everyday objects describe a need, not an object class. The robot turns that request into the right object and a plan to fetch it, all on the robot itself, with no cloud.

    Speak a need→Detect objects · PYNQ-Z2 FPGA→Rank by meaning · CLIP→Plan the motion→Fetch & tell the user

    Wheelchair-mounted arm

    Users with limited arm movement (spinal cord injury, ALS) ask the arm to bring items from a table.

    “something to drink from” → cup

    Elderly care at home

    A home robot fetches the phone, remote or glasses, so the user doesn't have to get up.

    “I need to call someone” → cell phone

    Visual impairment

    The system finds the object and says where it is, so the user can reach it themselves.

    “something to sit on” → chair, “to the right”

    Hospital bedside

    Bed-bound patients ask for nearby items without calling a nurse for every small request.

    “something to read” → book
    Inside the system

    Hardware–software co-design on the PYNQ-Z2

    The Zynq SoC pairs FPGA fabric with an ARM processor on one chip. Compute-heavy convolution runs in programmable logic; flexible, language-driven reasoning runs in software on the processor. Nothing leaves the robot.

    INPUTUser task (text / voice) + robot camera frame
    →
    OUTPUTSelected object · confidence · score · bbox → navigate / grasp
    PYNQ-Z2 · Xilinx Zynq-7000 XC7Z020 SoC

    Programmable Logic

    PL · FPGA fabric · Model 1
    • Tiny YOLOv2 INT8 hardware overlay
    • Convolution MACs DSP48E1
    • Feature-map line buffers BRAM
    • Leaky ReLU + bias LUT logic
    • Emits class, confidence, bbox per object

    Processing System

    PS · Dual ARM Cortex-A9 · Model 2
    • Detection filtering + NMS Python
    • CLIP text / image encoder 512-d
    • Cosine similarity ranking a·b / ‖a‖‖b‖
    • Score fusion + argmax select orchestrator
    • JSON + annotated frame out HDMI / SSH
    ⇄ Shared DDR3 (512 MB) · AXI DMA / VDMA · zero-copy buffers (pynq.allocate) between PL and PS ⇄
    XC7Z020Zynq-7000 SoC on PYNQ-Z2
    INT8Quantized detector weights in PL
    ~30 FPSOn-board detection target
    < 15 WPower envelope for a mobile robot
    512-dCLIP embedding space for ranking
